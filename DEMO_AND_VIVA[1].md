# Demonstration and Viva Guide

## Suggested demonstration
1. Start the program.
2. Choose option 10 to load 40 demonstration records into an empty register.
3. Choose option 3 to view records.
4. Choose option 5 to explain the executive summary.
5. Choose option 6 to generate the two charts.
6. Choose option 7 to export reports.
7. Choose option 4 to search by tree name or location.
8. Choose option 0 to save and exit.

## Viva Questions
1. **Aim:** To maintain plantation records and monitor survival through follow-up inspections.
2. **Language:** Python 3.
3. **Storage:** JSON primary file and CSV copy.
4. **Survival rate:** Total alive count divided by total inspected count, multiplied by 100.
5. **CSV:** A comma-separated text format used for importing/exporting tabular records.
6. **Duplicate prevention:** Import skips matching tree name, quantity, location, date and planted-by values.
7. **Chart library:** Matplotlib.
8. **Future scope:** Web/mobile interface, GPS tagging, database-backed multi-user access, reminders and field sensor integration.

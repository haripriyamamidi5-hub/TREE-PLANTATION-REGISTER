# Tree Plantation Register

## Project Description
Tree Plantation Register is a Python-based application developed to maintain plantation records and monitor tree survival.

## Features
- Add plantation records
- Record tree survival follow-ups
- View and search plantation records
- Generate executive summaries
- Generate plantation and survival charts
- Import and export CSV files
- Track overdue follow-ups

## Technologies Used
- Python
- CSV
- JSON
- Matplotlib

## How to Run
1. Download or clone this repository.
2. Install the required packages:
   `pip install -r requirements.txt`
3. Run the application:
   `python tree_register.py`

## Project Purpose
The main objective is to maintain plantation information, monitor tree survival, and support effective plantation management.
